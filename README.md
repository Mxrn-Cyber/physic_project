## 📖 Overview

Physics Project is an interactive educational platform that helps students explore physics concepts through engaging lessons, animations, quizzes, and practical examples.

---

## ✨ Features

- 📚 Interactive learning modules
- 🎥 Educational videos
- 📝 Practice quizzes
- 📊 Progress tracking
- 📱 Responsive design
- 🌙 Modern UI/UX

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Mxrn-Cyber/physic_project.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

---

## 📦 Build Production

```bash
npm run build
```

Preview:

```bash
npm run preview
```
